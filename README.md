# Mi Plan releases

Android installers (APK) of Mi Plan, a personal money app. This repository holds only releases and their notes, no source code.

## Installing

Download the APK from the [latest release](https://github.com/thongsinhv-bit/mi-plan-releases/releases/latest), open it, and allow installs from that app when Android asks. Installing over an older version keeps your data.

Google Play Protect may block an app from a developer it has not seen before. If the warning offers "More details" and then "Install anyway", choose them. If it offers no way to install, stop.
